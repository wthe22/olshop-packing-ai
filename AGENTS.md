# Rules for coding agents

- Start with `docs/development/README.md`, then `docs/development/plan.md`: the first
  unfinished phase and its unticked tasks (in `docs/<desktop|mobile>/phases/pNN-*/plan.md`) are
  the work. Read the design files the phase lists.
- `samples/` and `work/` are **confidential** real data. Never commit them; never copy real
  IDs, names, phone numbers or addresses into code, tests, docs or commit messages. Use made-up
  values (`JY0000001234`, `580000000000000001`). Committed fixtures live in `testdata/` and are
  generated by `testdata/make_testdata.py`.
- Docs: `docs/business-process/` = facts true without the tools; `docs/shared/` = what both
  tools share (rules file, conventions); `docs/desktop/` (PC app) and `docs/mobile/`
  (Android) each hold `design/` = what to build, `development/` = setup log and commands,
  `phases/pNN-name/` = a phase's `plan.md` and its owner reviews `review-N.md`, and (desktop)
  `user-guide/` = how to use a finished tool (for the owner); `docs/development/` = rules, plan
  and status of all phases. Current state only, no change history. A design change found while
  coding is written into the platform's `design/` in the same commit.
- Naming: timestamps `*_time` (`create_time`, `import_time`). Items are identified only by
  `SKU ID`; orders by `Order ID`.
- Log every one-time setup step in the platform's `docs/<desktop|mobile>/development/01-setup.md`.
- Commit after each finished task and tick it in the phase's `plan.md`; push to `origin main`.
  The owner reviews at the end of each phase before the next starts; the review is attached to
  the phase as `review-N.md` in its folder.
- The owner is often away and may answer a review in a new session. Whenever the next step
  is the owner's, end with a committed handoff in the Status block of `docs/development/plan.md`:
  what to review, where to write answers, and what to do with each answer. A new session starts
  there.
- Shell is Git Bash on Windows. Python: `.venv/Scripts/python.exe` (created from
  `C:\Python314`), only for `tools/analysis/` (analysis helpers, not product code).
- The owner decides open choices: put them in the platform's `docs/<desktop|mobile>/design/02-design-questions.md`
  with options, do not pick silently.
