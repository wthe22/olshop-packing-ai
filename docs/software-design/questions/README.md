# Open questions

Questions that need the owner's choice. Each explains the problem, gives options with an example of what the
owner would see, and marks one **Default**: what the app does until the owner decides, so the work is not
blocked.

A question is removed once its answer is written into the design files and recorded in
[decisions/](../decisions/README.md). A new question takes the next free number of its scope (the last ones
used: `Q-LABEL-12`, `Q-APP-11`, `Q-UI-8`, `Q-RULES-2`); numbers are never reused.

| File | Open questions |
|---|---|
| [app.md](app.md) | Q-APP-12 to Q-APP-17: the word *account*, v0.4 data, batch numbers across dates, an account's summary PDFs, an unknown shop, deleting an account |
| [ui.md](ui.md) | Q-UI-9, Q-UI-10: the page of one account, the panel without a workspace |
| [rules.md](rules.md) | Q-RULES-3: account and shop in the filter language |

A new question goes into a file per scope (`label.md`, `app.md`, `ui.md`, `rules.md`), listed here.
