# Decisions

Settled choices of the owner that shape the design, one record each. The rule itself is written in
the design files; a record gives the reason and links to where the rule applies.

IDs are `D-<SCOPE>-n`; the scopes are listed in [../../README.md](../../README.md#scopes). A number is
never reused. A decision that changes gets a new record that names the one it replaces.

| File | Scope | Records |
|---|---|---|
| [label.md](label.md) | LABEL | D-LABEL-1, D-LABEL-2, D-LABEL-4: courier data file, the two-clue rule, remembered logos |
| [app.md](app.md) | APP | D-APP-1 to D-APP-2: the PDF library, the check before saving |

Open choices are in [../questions/](../questions/README.md).
