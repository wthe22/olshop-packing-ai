# 02 — Design Questions

Open questions only. Each one is undecided until the owner chooses.

### D1 — Where are categories edited?
The PC script and the app use the same `categories.json`.
- a. In the app (the same condition editor as scan filters); exported to the PC as
  `categories.json`.
- b. As a text file on the PC; imported into the app.
- c. Both: edit in either place, move the file both ways.
