## R-LABEL-16 — The tracking ID of a TikTok Shop Sameday order

**Present.** The tracking ID of a TikTok Shop Sameday order is empty. Its label prints the code under
`Kode Pengambilan`, which the app reads only as the pickup code, so the order shows *no tracking ID*.

**Wanted.** The code under `Kode Pengambilan` is the order's tracking ID: two capital letters and four digits, as
in `BC0000`. The sample label is `samples/2026-11-24 sameday.pdf`.
