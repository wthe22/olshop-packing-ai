# UI: the owner's feedback

The owner's findings on the window and the screens. Open items only; see [README](README.md) for the form.

## R-UI-53 — The source PDF's short hash in an expanded search result

**Present.** An expanded search result shows its details, but not the short hash of the source PDF it came from,
so the owner cannot tell which file to open.

**Wanted.** The expanded result also shows the source PDF's short hash, the same one its file name carries, so the
owner can find the file.
