Agreed with the owner on 2026-10-25. [code-rules.md](../code-rules.md) applies to every task; a task report
states *size gate passed, no new lint suppression, coverage not lower*. The design to build is
[software-design/](../../software-design/README.md); start with its [workflow](../../software-design/workflow/README.md).

## What the owner asked for

- A data-driven design: efficient storage, no duplicated truth, ACID without a database, extensible (a
  feature adds a field, never a schema change), reads cached for fast search, every value traceable to its
  source for debug and audit — and nothing over-engineered.
- The architecture and the algorithms documented for audit.
- New: search orders, select some, and write one PDF of their labels to reprint.
- Correctness first, no single point of failure: what checks an output is never the code that made it.
- Few options with sensible defaults, each default visible where it acts. Good UX. No code or design smell.

## Spike (2026-10-25)

On 1,309 pages (11 real downloads and `testdata/labels-slip.pdf`), every page PDFium copied — through the
joined document, in reversed order — has the same `lopdf` digest as its source page, and every page of a
file has a digest of its own. The spike code was scratch and is not kept; [the page digest](../../software-design/app/verification.md#the-page-digest)
is its algorithm.
