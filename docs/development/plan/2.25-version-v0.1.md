# 2.25 The version in the window title and in *About*, from one place

**Goal.** The program shows its version the way the owner asked (R-UI-1): **v0.1** in the window title
and in the title bar of every screen, and *Version v0.1* in Settings › *About*
([Settings › The version](../../software-design/ui/settings.md#the-version),
[the window frame](../../software-design/ui/README.md#window-frame)). The number has **one place**:
the workspace `version` in the root `Cargo.toml` (`0.1.0` today). The shown form is `v` + the first
two numbers (`0.1.0` → `v0.1`) and is made in one function of the app crate, used by the window
title, the title bar and *About*, so the three cannot differ. `app/src-tauri/tauri.conf.json` loses
its `version` key and its window `title` carries no number (Tauri then takes the version of
`app/src-tauri/Cargo.toml`, which the app inherits from the workspace), so no second copy exists that
could disagree; `app/package.json`'s own `version` is npm's field, shown nowhere, and a test keeps it
equal to the workspace version.

- **Design to read:** [ui/settings.md](../../software-design/ui/settings.md#the-version),
  [ui/README.md](../../software-design/ui/README.md#window-frame),
  [ui/day.md](../../software-design/ui/day.md) (its title line),
  [app/program.md](../../software-design/app/program.md) (*About*), and
  [ui/start.md](../../software-design/ui/start.md) (the title bar on the first start).
- **Code (likely):** `Cargo.toml` (the workspace `version`: read only, it is the one place);
  `app/src-tauri/tauri.conf.json` (drop `version`; a window `title` with no number);
  `app/src-tauri/src/commands/day.rs` (`version_text()` = `v` + major.minor of
  `env!("CARGO_PKG_VERSION")`; `about()` returns it; `StartInfo` carries it); `app/src-tauri/src/lib.rs`
  (the window title set at start, on the Rust side — setting it from the window would need the
  `core:window:allow-set-title` permission in `app/src-tauri/capabilities/default.json`, which no
  screen needs); `app/src/lib/Frame.svelte`, `app/src/lib/api.ts` and `app/src/texts.ts` (the title
  bar's brand text = the program name + the version); `app/package.json` (its `version`, kept equal
  to the workspace's).
- **Tests:** Rust (`app/src-tauri/src/commands/day.rs`) — `version_text()` is `v` + major.minor of
  `env!("CARGO_PKG_VERSION")` (so a changed workspace version changes the shown text); the window
  title text and *About* both come from that one function (a literal in either spot fails the test);
  `tauri.conf.json` holds no `version` key and no number in its window `title` (read with
  `include_str!` at compile time). Front-end (`app/tests/version.test.mjs`) — the title bar's text
  for `v0.1` is *Packing v0.1*; `app/package.json`'s `version` equals the workspace `version` read
  from `../Cargo.toml`.
- **Gates:** `cargo fmt --all --check`; `cargo clippy --workspace --all-targets -- -D warnings`;
  `cargo test --workspace` (add `-j 1` when linking runs out of memory); in `app/`:
  `npm run check` and `npm test` ([app.md](../app.md)).
- **Close:** `bash tools/make-portable.sh` ([AGENTS.md](../../../AGENTS.md)), check the built program
  folder shows *Packing v0.1* in its title bar and *Version v0.1* in *About*, then update the user
  guide where the title and the version appear
  ([a day](../../user-guide/02-a-day.md), [messages and settings](../../user-guide/04-messages-and-settings.md))
  and retake the pictures whose title bar shows the old title, in the same commit, and delete this task
  file in that commit.
