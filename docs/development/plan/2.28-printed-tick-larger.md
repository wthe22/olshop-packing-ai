# 2.28 The Printed tick: larger, no word (R-UI-3)

The saved-PDF row of the [Day screen](../../software-design/ui/day.md) has a small **Printed** tick box
with the word *Printed* beside it (2.26). The owner wants the tick box as large as the **Open** button
of the same row, and the word gone: the tick alone says the PDF is printed
([R-UI-3](../../reviews/ui.md)).

- The box's height and width equal the **Open** button's height; the word is not drawn. The tick keeps
  an accessible name (`aria-label` from `texts.ts` `printedLabel`, tooltip too), so it stays usable by
  keyboard and readers. A click still saves the tick in `state.json` as before.
- Files: `app/src/lib/DayScreen.svelte` (markup and style), `app/src/texts.ts` (`day.printed` text is
  dropped if unused), `app/src/lib/printed.ts` only if it needs changing.
- Design: the row picture in [day.md](../../software-design/ui/day.md) (`[✓]` replaces `[✓] Printed`,
  and the row text says the tick has no word and is as large as **Open**); the user guide
  ([a day](../../user-guide/02-a-day.md)) wherever it names the *Printed* word.
- Delete R-UI-3 from [reviews/ui.md](../../reviews/ui.md) and fix the open-items line in
  [reviews/README.md](../../reviews/README.md).
- Gates: in `app/`: `npm run check` and `npm test` ([app.md](../app.md)); the Rust gates only if Rust
  changed.
