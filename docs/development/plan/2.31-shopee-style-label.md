# 2.31 The Shopee-style label packs (Q-LABEL-4)

The owner sent `samples/2026-10-15 spx.pdf` with *add support for* it: three Shopee-style pages,
one order a page. The batch now stops on its first page (*page 1 has no Order ID*), because the
style prints no 18-digit Order ID and its slip is named in Indonesian. The owner's choice is
[Q-LABEL-4](../../software-design/questions/label.md) option 1, its **Default** (the app packs the
style); this task builds it and the question goes.

- **The order key.** `crates/engine/src/label/fields.rs`: `find_order_id` gains a last step — the
  raw search for `5` + 17 digits, then the collapsed `OrderID:` search, then the collapsed
  `No.Pesanan:` caption (six digits then eight letters/digits, the style's own 14-character
  number). Last, so no other style changes.
- **The deadline.** `find_ship_by` also reads `Batas Kirim: dd-mm-yyyy` (hyphens, no time): the
  order's `ship_by` is that day at 00:00.
- **The slip.** `crates/engine/src/slip.rs` gains the style's header
  (`# Nama Produk SKU Variasi Qty`) beside the English one, each header naming the **role** of its
  columns: the English `SKU` column holds the variation, the Shopee `SKU` column the seller SKU and
  its `Variasi` column the variation. The header words are found in the line's joined text, because
  the style's runs split a word (`Variasi` comes as `V` + `ariasi`, a font change inside the word).
  The table's last row is bounded by `Qty Total` **or** the style's `Pesan:` line, which is what
  prints under the table when there is no `Qty Total`.
- Files: `crates/engine/src/label/fields.rs`, `crates/engine/src/slip.rs`,
  `crates/engine/src/ids.rs` (the `OrderId` comment), tests in `crates/engine/tests/`.
- Design: [reading.md](../../software-design/labels/reading.md) (the key search, the two slip
  headers and their roles, the table's end, `ship_by`), [courier.md](../../software-design/labels/courier.md)
  item 9, [requirements.md](../../software-design/requirements.md) (`Order`'s key),
  [decisions/label.md](../../software-design/decisions/label.md) (D-LABEL-5) and the question file,
  which loses Q-LABEL-4.
- Gates: `bash tools/check.sh --coverage`; `bash tools/make-portable.sh`; the file reads with
  `packing-cli prepare` (3 orders, 3 runs, no warnings, courier SPX once the `Shopee` strip is
  answered *Not a courier*). Report: size gate passed, no new lint suppression, coverage not lower.
