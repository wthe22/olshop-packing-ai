# 2.29 A set of categories is called a *Grouping* (R-UI-4)

The owner wants a set of categories called **Grouping**, everywhere the owner or a design file says
*set* for it ([R-UI-4](../../reviews/ui.md)): *Grouping: [default ▾]* on New batch, **+ New grouping** and
**Delete grouping** on Categories, the grouping's name in the Plan header, the Amend confirmation of
the Day screen, error and note texts. Only this word changes. A *PDF set* (the PDFs one batch saves)
keeps its name. Code names (`set` in `state.json` and `settings.json`, `sets_list`, `new_set`,
`delete_set`, the `categories/` folder, file formats) do **not** change: only the words the owner
reads change, plus the design and user-guide prose.
