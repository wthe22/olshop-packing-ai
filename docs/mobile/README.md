# Mobile — Android app

The phone side of the packing work: the **Android app** (Kotlin, `android/`) that checks every
packed parcel by scanning its label with the phone camera. **Not started**: the design is still
the old one and is revised before phase 3; phase 3 waits for the desktop phase-2 review.

| Folder | Contains |
|---|---|
| [`design/`](design/README.md) | Requirements, open questions (D1), architecture, screens |
| [`development/`](development/README.md) | Setup log (`01-setup.md`) and commands |
| [`phases/`](phases/) | One folder per phase: `plan.md` (tasks) and `review-N.md` (owner review). Phases 3–7: camera spike, app core, scanning, files and settings, layouts and polish |

Status and the next step: [`../development/plan.md`](../development/plan.md).
