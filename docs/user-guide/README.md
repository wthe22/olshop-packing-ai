# User guide

For the shop owner: how to use the app **Packing** on a Windows PC and do the daily work — bring in
the label downloads, check the plan, save and print. Plain words, not for a developer.

| File | Covers | Read when |
|---|---|---|
| [01-setup.md](01-setup.md) | What the app is; putting the program folder on a PC; the first start; a new version of the program | once, before the first day of packing |
| [02-a-day.md](02-a-day.md) | The window and the panel; a normal batch, step by step; repeated orders; several batches a day; finding and reprinting a saved order | every day, while packing |
| [03-changes.md](03-changes.md) | Reverting or amending the last batch; editing the sort rules | a batch or a sort rule needs changing |
| [04-messages-and-settings.md](04-messages-and-settings.md) | The messages and what to do; the settings | a message appears, or a setting is changed |

This guide matches the screens of the current app (version 0.2). The pictures in [`images/`](images/) are
the real program on the made-up `testdata/` labels, so no real order data appears; `node
tools/guide-pictures.mjs` takes them again after `bash tools/make-portable.sh`.
